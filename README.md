# Préstamo de Herramientas

Aplicación simple para gestionar el préstamo de herramientas en un pañol para mecánicos. Está basada en [Flask](https://flask.palletsprojects.com/).

## Requisitos

- Python 3.11
- pip

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

## Uso

Ejecutar la aplicación con:

```bash
python app.py
```

La aplicación quedará disponible en `http://localhost:5000`.
